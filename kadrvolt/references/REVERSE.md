# Разбор видео и перенос приёмов

В архиве есть CLI, лицензия и оригинальные инструкции [rea-video](https://github.com/JuneYaooo/rea-video). Русский процесс ниже использует снимок `fabf832d6b136672be4ed9bff1739d0e6d6788af`. Для запуска нужны uv, FFmpeg и Python 3.10+ (проверен Python 3.12). При первом запуске uv загружает недостающие зависимости, а движок может скачать небольшую модель для обнаружения лиц. Локальный маршрут анализирует файл на компьютере. Копия оригинальной инструкции: [UPSTREAM_SKILL](../vendor/rea-video/skills/rea-video/UPSTREAM_SKILL.md).

```sh
uvx --python 3.12 --from "$STUDIO/vendor/rea-video" rea-video --help
uvx --python 3.12 --from "$STUDIO/vendor/rea-video" rea-video \
  decompose reference.mp4 -o out/reference --lang en --no-vlm --no-stems --no-ocr
uvx --python 3.12 --from "$STUDIO/vendor/rea-video" rea-video summary out/reference/breakdown.json
uvx --python 3.12 --from "$STUDIO/vendor/rea-video" rea-video review out/reference
```

- Сначала открой `storyboard.jpg` и `report.html`, затем проверь стыки и кадры с низкой уверенностью. Для кадра, который движок не разделил, предложи точный таймкод после просмотра. Выдели базовый видеоряд, титры, перебивки, графику, музыку, SFX и материалы, которые нужны от пользователя.
- При визуальной проверке заполни реально просмотренные позиции в `review_answers.json`, сохраняя неизвестные. Внеси изменения через `rea-video apply-review out/reference --by studio --lang en` с тем же префиксом uvx.
- Отдельно проверь русский текст по кадрам или через русский ASR. Базовый запуск выше отключает OCR и разделение дорожек. При необходимости разделения посмотри `rea-video stems --help`. VLM и дополнительные модели включай отдельно. Для VLM используй документированный `--env-file` и согласуй, какие материалы передаются провайдеру. Исходный CLI формирует HTML на английском или китайском, а пользователь получает краткий разбор и при необходимости отдельный `report_ru.md`.
- При /reverse выдай отчёт, контакты кадров и таблицу `таймкод → наблюдение → возможный метод → уверенность`. При /remake используй эту таблицу в раскадровке. Реальные исходники, лица и продукты бери из материалов пользователя. Анимацию и титры собирай слоями в нужном движке.
- Если вход — URL, используй доступный файл или согласованный способ получить ролик. Если анализатор недоступен, собери контакты кадров и аудио через FFmpeg и проверь визуально. Укажи метод и пределы вывода.
