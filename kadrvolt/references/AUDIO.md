# Голос, субтитры и звук

## Выбор озвучки

1. Если запись дана, извлеки/сохрани её и измерь точную длину. Речь и её порядок меняются только по задаче. Подрежь паузы и шум так, чтобы не потерять окончания.
2. Если пользователь хочет голос и записи нет, предложи записать текст самостоятельно или использовать синтез. Для записи дай финальный текст и пару подсказок по темпу. Для немого ролика этот шаг можно пропустить.
3. Для ElevenLabs согласуй текст, язык, голос (Voice ID) и использование кредитов аккаунта. Возьми выбранный пользователем голос из [Voice Library](https://elevenlabs.io/app/voice-library) или его аккаунта. Для клонирования нужен голос, которым он вправе пользоваться. Ключ создаётся в [аккаунте ElevenLabs](https://elevenlabs.io/app/settings/api-keys). Пользователь помещает его в локальную переменную `ELEVENLABS_API_KEY` или доступный секрет менеджера. В чат, историю, проект и Git ключ не попадает.
4. Сначала сделай короткую пробу, если пользователь выбирает тембр или произношение. После её согласования озвучь финальный текст. Если текст уже утверждён и голос выбран, сразу сгенерируй нужный результат. Скрипт отправляет файл текста в API ElevenLabs и записывает MP3.

```sh
python3 "$STUDIO/scripts/elevenlabs.py" script.txt "VOICE_ID" audio/voice.mp3
ffprobe -v error -show_entries format=duration -of csv=p=0 audio/voice.mp3
```

У скрипта есть `--model`, значение по умолчанию `eleven_multilingual_v2`. После генерации прослушай имена, числа и ударения. Поставь сцены и субтитры по реальному звуку. При ошибке проверь конфигурацию, статус и файл вывода, прежде чем повторять платный запрос. [API ElevenLabs](https://elevenlabs.io/docs/api-reference/text-to-speech/convert)

## Субтитры

- При готовых SRT/VTT проверь язык и диапазоны. Для транскрипции используй доступный Whisper с русским языком или согласованный ASR. Исправь имена, цифры и переносы после прослушивания. Сохрани таймкоды. При монтаже пересчитай диапазоны на финальный таймлайн.
- Для вшивания используй Remotion/HyperFrames либо FFmpeg с фильтром `subtitles` (сборка с libass). Учитывай шрифт с кириллицей. В HTML/React используй тот же SRT как источник, форматирование задавай отдельно. Проверь стыки, края, переносы и безопасную зону.
- Сохрани `captions.srt` в UTF-8. Словарная или приблизительная разметка требует проверки по слышимому звуку, особенно для подсветки отдельных слов.

## Сведение

Храни голос, музыку и SFX раздельно. В совместном звучании важнее разборчивость речи. Синхронизируй эффекты с видимыми событиями, применяй фейды и проверь отсутствие перегруза. Для контроля измеряй integrated LUFS и true peak через `ffmpeg -af loudnorm=print_format=json -f null -` с нужным `-i`. Цель зависит от площадки. Прослушай обычную и тихую громкость. Не применяй нормализацию повторно без проверки.

Чтобы заменить дорожку готовой анимации, измерь звук и видео. Если речь помещается полностью, используй:

```sh
ffmpeg -n -i picture.mp4 -i audio/voice.mp3 -map 0:v:0 -map 1:a:0 \
  -c:v copy -c:a aac -b:a 192k -af apad -shortest -movflags +faststart final.mp4
```

Для исходной речи с музыкой используй `amix` после снижения уровня музыки или `sidechaincompress`. Для сложного микса работай на раздельных дорожках проекта. Проверяй финальный аудиопоток и его синхронность.
