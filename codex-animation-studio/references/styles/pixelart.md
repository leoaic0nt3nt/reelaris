# Пиксель-арт

## Визуальный язык
Чёткие пиксельные кластеры и узнаваемые спрайты в духе 16-битной графики. Создавай рисунок в низком логическом разрешении; простой фильтр поверх фотографии не заменяет форму.

## Реализация
Работай на 180×320 для вертикального 1080×1920, увеличивай ×6 через nearest neighbor без сглаживания. Целые координаты, контур в 1 логический пиксель, 3-5 тональных групп на материал, палитра из сюжета. Стабильный ordered dithering вместо меняющегося шума.

## Движение
Шаговые позы, моргание, дискретное движение на двойках, локальное дыхание, параллакс слоёв. Эффекты и частицы привязывай к сетке; плавный субпиксельный дрейф ломает стиль.

## Проверка
Нет размытого ресэмплинга, случайного аркадного HUD, одинакового фиолетового заката для любой темы или неузнаваемого героя. Субтитры по запросу: читаемый растровый шрифт с контрастной тенью.
