# Движки и локальная сборка

`STUDIO` — абсолютный путь к установленной папке, содержащей SKILL.md. Команды запускай из папки отдельного видеопроекта. Сначала проверь `ffmpeg -version`, `ffprobe -version`, `node --version` и только необходимые зависимости.

## HyperFrames

Выбирай для новых HTML/CSS/SVG-композиций, титров, сайтов, видео со слоями и графики поверх исходников. Открой официальный скилл HyperFrames, если он установлен. Для новой работы прочитай подходящий маршрут. Для продолжения используй существующие файлы проекта и его версию CLI.

Из копии `templates/hyperframes` можно сразу проверить композицию и экспорт:

```sh
npm ci
npx --yes hyperframes@0.9.26 check .
npx --yes hyperframes@0.9.26 render . --fps 24 --output demo.mp4
```

Нужны Node.js 22+, Chromium и FFmpeg. При отсутствии браузера используй `npx --yes hyperframes@0.9.26 browser ensure`. Для просмотра таймлайна: `npx --yes hyperframes@0.9.26 preview .`. В существующем проекте используй зафиксированную там версию. Для готовых эффектов сначала ищи нужное движение в `hyperframes catalog --query "…"`. При включении блока из реестра проверь размеры, пути и треки.

Для прямых нарезок задавай `data-start` на таймлайне, `data-media-start` в исходнике, `data-duration` и `data-track-index`. Фиксируй размеры корневого элемента, локальные ассеты и временную шкалу. Анимация должна восстанавливать любой кадр при перемотке.

Документация и скиллы: [HyperFrames](https://github.com/heygen-com/hyperframes).

## Remotion

Выбирай для существующих React-композиций, шаблонов на данных и многократно используемой графики. Для новой работы скопируй `templates/remotion` в отдельную папку:

```sh
npm ci
npm run studio
npm run render
```

В шаблоне `src/index.jsx` один `Composition`. Меняй движение через `useCurrentFrame`, `interpolate` и `spring`. Медиаклипы сдвигай через `Sequence`. Для файлов используй `public/` и `staticFile()`. Задавай длительность в кадрах, сначала проверяй несколько кадров. При установке официальных скиллов Remotion выбирай нужный раздел: композиция, медиа, субтитры или экспорт.

[Скиллы Remotion](https://github.com/remotion-dev/skills) · [Рендер](https://www.remotion.dev/docs/cli/render) · [Условия использования](https://www.remotion.dev/docs/license)

## FFmpeg

Быстрая сборка для материалов с точными диапазонами. Перед разметкой посмотри видео, прослушай речь и измерь файлы через ffprobe. Сохрани диапазоны как JSON в папке проекта. Пути относительны к JSON, секунды `in` включительно и `out` до границы следующего кадра. Для окончательных стыков сверяй звук на слух.

```json
{
  "width": 1080,
  "height": 1920,
  "fps": 24,
  "clips": [
    {"file": "media/intro.mp4", "in": 0, "out": 2.5},
    {"file": "media/main.mov", "in": 4.2, "out": 15.5}
  ]
}
```

```sh
python3 "$STUDIO/scripts/cut.py" timeline.json out/rough-cut.mp4
```

Скрипт сохраняет пропорции, добавляет поля при несовпадении форматов, добавляет тишину на фрагментах без звука и выводит H.264/AAC. Для смыслового вертикального кадрирования, графики, переходов и параллельных слоёв используй HyperFrames, Remotion или монтажный проект пользователя. Для HDR, нестандартной цветовой обработки или альфа-канала согласуй формат и используй отдельную цепочку. В таймлайне указывай путь к исходнику и запись о любой переработке.

## Покадровый HTML

`scripts/render_video.mjs` из первого выпуска студии. Для самостоятельного HTML/Canvas/SVG/WebGL, где можно вызвать `window.renderFrame(f)`. Нужны Node.js, Playwright и Chromium в проекте. Режим для локальных ассетов и без аккаунта. Команда и контракт в [рендере](RENDERING_AND_QA.md).
