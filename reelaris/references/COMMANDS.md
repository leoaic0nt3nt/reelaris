# Меню студии

Понимай обычную речь. В Codex пользователь может выбрать скилл или ввести `$reelaris`. В Claude Code вызови `/reelaris`. Текстовые селекторы можно сочетать, например `/create /pixelart`. При нескольких несовместимых стилях предложи деление на сцены или попроси выбрать один.

| Селектор | Что попросить |
|---|---|
| `/start`, `/help` | «Расскажи, что умеешь, и помоги начать» |
| `/styles` | «Покажи стили для анимационной истории» |
| `/create` | «Сделай 20-секундный эксплейнер по моему сценарию» |
| `/edit` | «Собери Reels из этих файлов, сохрани мою речь» |
| `/reverse` | «Разложи референс по кадрам и объясни, как повторить приёмы» |
| `/remake` | «Примени темп и графику референса к моим исходникам» |
| `/voice` | «Помоги выбрать голос или подключить ElevenLabs» |
| `/captions` | «Сделай русский SRT и версию с вшитыми субтитрами» |
| `/preview` | «Покажи раскадровку и короткий черновик» |
| `/export` | «Экспортируй текущий проект в 9:16» |
| `/tools` | «Проверь движки и предложи расширение для моей задачи» |

## Десять стилей

| Селектор | Что увидит зритель |
|---|---|
| [`/pixelart`](styles/pixelart.md) | Чёткие пиксели, ограниченная палитра, ступенчатое движение. Подходит для игровых метафор и ретро. |
| [`/chalkboard`](styles/chalkboard.md) | Мел, доска, штриховка и рисунок, возникающий по ходу объяснения. |
| [`/glowsketch`](styles/glowsketch.md) | Светящиеся контуры и импульсы на тёмном фоне. Для энергии, сетей и технических схем. |
| [`/ps2`](styles/ps2.md) | Угловатая геометрия, жёсткий свет, низкополигональная игровая эстетика. |
| [`/comicart`](styles/comicart.md) | Панели, тушь, растр, резкие ракурсы. Для конфликта и коротких историй. |
| [`/flatvector`](styles/flatvector.md) | Чистые формы, ровные заливки, ясная схема движения. Для процессов и интерфейсов. |
| [`/dankoe`](styles/dankoe.md) | Тонкие белые линии, минимум деталей, паузы и графические метафоры. |
| [`/cgimotion`](styles/cgimotion.md) | Объём, материалы, отражения и кинематографический свет. Для предметов и презентаций. |
| [`/legostyle`](styles/legostyle.md) | Игрушечные кирпичики, сборка по шагам, механическое движение. |
| [`/zackdfilms`](styles/zackdfilms.md) | Упрощённая объёмная реконструкция, детали механизма и движение камеры. |

Движение и формы можно сравнить в [галерее GitHub](https://github.com/leoaic0nt3nt/reelaris#демо). Для проекта с видео предложи стиль только там, где он улучшает чтение: перебивки, схемы, титры, фон или обработка кадра.
